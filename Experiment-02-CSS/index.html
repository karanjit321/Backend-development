Demonstration of Inline, Internal and External CSS

Types of CSS

CSS is used to control the presentation, layout and appearance of HTML documents. There are three common ways to apply CSS.

1. Inline CSS

This paragraph is styled using Inline CSS.

Inline CSS is written directly inside an HTML element using the style attribute.

<p style="color: red;">Inline CSS</p>

2. Internal CSS

Internal CSS Example

This section is styled using CSS written inside the <style> element of the HTML document.

<style> .internal-style { color: blue; } </style>

3. External CSS

External CSS Example

This section is styled using a separate style.css file.

<link rel="stylesheet" href="style.css">

Comparison of CSS Types

CSS Type Location Advantage Best Used For
Inline Inside HTML element Quick styling Specific elements
Internal <style> section Single-page styling Individual webpages
External Separate .css file Reusable and organized Multiple webpages

Conclusion

This experiment demonstrates the three major methods of applying CSS: Inline CSS, Internal CSS and External CSS. External CSS is generally preferred for larger projects because it keeps the presentation separate from HTML content.
